# Moji 1.4.0 (38)

Moji 1.4.0 是首个 iOS / Android 双端版本。

## Android

- 完成计划、日历、备忘、倒数日、纪念日、番茄钟、回顾和设置四栏工作流。
- 支持 Room 本地数据、计划提醒、系统日历、自动备份及恢复。
- 提供计划、倒数日和纪念日三个桌面组件。
- 番茄钟使用绝对结束时间，后台或重启后可恢复，并通过系统通知提示完成。

## 双端

- 共用 schema 12 / backup format 1，可在 iOS 与 Android 之间迁移数据。
- 共用版本号、核心日期/统计/番茄周期策略和发布脚本。
- iOS 的 Bundle ID、Widget ID 与 App Group 保持不变，原有本机数据可直接升级。
