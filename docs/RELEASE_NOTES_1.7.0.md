# Moji 1.7.0（45）

作者：Jerry Wong。日期：2026-11-18。

本版只改 Android 的界面外观。以 iOS 1.6.2 为准，逐页对照两端截图，把 Android 的图标、颜色、字号、间距和分隔线改得与 iOS 一致。iOS 代码没有改动，功能和数据格式都没有变化。

## Android 界面

- **系统色。** 正文改用与 iOS 系统 label 相同的纯黑和纯白。次要文字、三级文字、分隔线和填充底色，改用 iOS 系统 secondaryLabel、tertiaryLabel、separator 和 tertiarySystemFill 的数值，浅色和深色各一套。
- **图标。** 底部四个标签页、计划页顶栏、表单行、返回键、展开箭头和设置页的图标，改成按 iOS SF Symbols 实测尺寸画的图形。置顶图钉改成实心，省略号的圆点加粗。“工作”“其他类型”和日期图标改成 iOS 的公文包、吊牌和日历形状；类型选择器和快速添加预设里，公文包和吊牌按 iOS 放大。
- **顶栏。** 一级页顶栏的高度改成和 iOS 一致。弹出页（sheet）的导航栏高 56，推入页高 44。返回键改用 iOS 样式的左箭头，尾部“+”改用图形。
- **表单。** 段标题和弹出页顶部的留白按 iOS 实测改了，第一段标题离卡片更远。多行输入框（计划和记录的详细说明、周复盘）的行距改成 22，和 iOS 一样。分隔线改成一个像素宽的系统分隔线色，叠放在行底，不再占高度。段标题和段脚注改成系统次要文字色。值文字、步进器加减号、分段控件的竖线、日期胶囊、行尾箭头，都按 iOS 改了。
- **计划。** 快速添加按钮、今日标题行、元信息行、备注行、详情行和更多操作，按 iOS 调整了图标和颜色。计划库的行距、批量选择和筛选箭头也改了。
- **备忘。** 搜索框、分组标题、正文行距、勾选圈和底栏图标改成与 iOS 一致。
- **时刻与专注。** 倒数日天数靠右对齐，底下洗墨的宽度跟随数字；专注的控制按钮改用与 iOS 相同的墨圈；时长单元按当前阶段改色。
- **回顾。** 完成率按基线对齐，下一步行和动作行改了高度和箭头，记录列表按类别配色，记录编辑器的合计行改成类别色，日历分段控件、墨痕分隔线和条目行间距也改了。周总结、月总结和时间记录三个弹出页去掉了左上角的“返回”，与 iOS 一样用系统返回关闭。记录编辑器的时长按钮改成“25 分钟”这样的写法。
- **设置。** 通知权限页和数据备份页的图标、行颜色和说明文字改成与 iOS 一致。
- **保存键。** 计划编辑页的标题框还空着、正在输入时，“保存”也能点，点了只收起键盘，不保存。iOS 本来就是这样，Android 原来在这种情况下是灰的。

两端系统字体不同（iOS 苹方，Android 思源黑体），字形宽度会有小差别，长段说明文字偶尔会在不同的字处换行，这一点不追求一致。

## 不变的地方

- iOS 代码没有改动。iOS 1.7.0（45）只是跟着升版本号重新打包，内容与 1.6.2 相同。
- 保留 App ID `com.raydon.minuteplan`、Android 包名 `com.raydon.moji.android`、schema 13，数据格式没有变化。
- Android 沿用原来的签名，可以直接覆盖安装 1.6.1。
