# Moji 1.5.0（40）

日期：2026-10-06。开发基线为最新 1.4.1（39），保留其数据安全、备份和性能维护成果。原定 1.5 与 1.6 两步合并为本次更新，不发布单独的 1.6。

## 从记录到行动

- 备忘列表的更多菜单新增“转为计划”；整篇正文、整份清单或单条清单项目均可转换。计划保存完整说明及备忘／清单来源，重复转换同一来源不重复创建。
- 计划的更多菜单新增“复制到今天”“复制到指定日期”“保存为模板”和归档。复制与模板实例保留标题、类型、说明、时间／时段、预计投入和提醒，不带完成状态、实际记录、日历绑定或原重复序列。
- 首页“＋”进入“计划库与模板”。搜索标题或说明，筛选类型、状态、过去／今天／未来和日期范围，查看跨日期计划及模板。
- 批量选择后可改日期、改类型和归档／取消归档。撤销逐条检查操作后状态，不覆盖其后修改、新增记录或正在计时的计划；撤销仅保留当前会话最近一次整理。

## 轻量目标与周复盘

- 周总结新增“计划 / 实际”：待完成、结转待办、未记录项数、预计投入和真实专注分钟，以及每项计划的预计／实际对照。
- 可选周目标：完成计划数、真实专注分钟或两者，支持全部类型及单一类型。数值范围 1–100000，编辑同一周／同一范围会更新原目标。
- 勾选完成不产生计时记录；未计时完成项显示“未记录”，不以预计时长替代实际时间。精确记录只计算与当周重叠的真实时段。
- 周复盘保存本周反馈、下周关注。选中待办后移动原计划到下周对应星期，保留原 ID、时间、说明及重复序列，不复制事项；正在计时的计划不会移动。

## Android 对齐 iOS

- 对齐四个首页、计划展开／完成折叠、编辑器、计划库、模板、备忘正文／清单、倒数／纪念、专注、回顾及记录页面的信息层级与主要操作。
- 复用相同水墨图片和篆书字体，统一浅／深色墨色及朱砂色、卡片形状、分隔线、文字行高、字号层级和工具栏；表单弹层、类型及安排方式选择、备忘勾选与底部工具栏同步对齐。
- 专注时长菜单、可选范围、计划时长归属、开始／暂停／提前结束／自然结束后的衔接一致。提前结束不完成关联计划；保留的是实际经过时间。开始专注时先结束本机旧计时，避免重叠计算。
- 编辑保存成功后才关闭；连续点击保存使用同一草稿 ID 防重复。编辑保留来源关联、归档标记和重复发生关联。
- 系统状态栏、手势／三键导航、权限、日期／时间／文件选择器及系统字体栅格化继续使用平台原生实现；iOS 实时活动等系统能力仍按平台实现，不扩展本轮范围。

## 数据与构建

快照 schema 从 12 升至 13，新增模板、周目标、周复盘数组及可选来源／归档字段。旧备份缺少这些字段时默认空值，不清除原数据；新字段参与备份校验和恢复。升级后的完整快照应使用新版本恢复，避免旧版本保存时忽略新增内容。

双端版本统一为 1.5.0／40，Bundle ID、App Group、Android 包名及既有签名密钥保持不变。APK 使用现有 Android Release 密钥；iOS IPA 未签名，需要自行重新签名。

本轮安装包由保留未提交改动的工作区直接构建，不代表 Git HEAD 的源码归档；未自动提交代码，未绕过 `Scripts/release.sh` 的干净工作区保护，也未上传商店。旧版本安装包保留。必要回归与视觉检查记录见 [1.5.0 验证记录](VERIFICATION_1.5.0.md)。
