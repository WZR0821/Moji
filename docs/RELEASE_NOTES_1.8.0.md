# Moji 1.8.0（46）

作者：Jerry Wong。日期：2026-11-20。

本版两端一起加了可选的「AI 整理」，并修好 iOS 上一个会让 App 卡在第一帧的问题。AI 默认关闭；没打开或没网的时候，界面和 1.7.0 一样。

## AI 整理（iOS 与 Android）

不加聊天页，也不加新的标签页。AI 只出现在已有的输入框和已有的操作里，结果都落成墨记本来就有的东西：计划、清单、复盘文字、筛选条件。模型给出的内容先以草稿显示（浅墨底、虚线框、一枚「稿」字小印），勾选或点了才写入；加进计划的草稿可以在提示条里撤销。

- **设置 → AI 模型。** 新的一页，按读屏那套做法配置供应商：预设的 ChatGPT、DeepSeek、Gemini、Claude、通义千问、豆包、Kimi、智谱 GLM、MiniMax，以及自定义 API（OpenAI 或 Claude 兼容接口）。每家各自填 API Key、获取可用模型、测试连接，用「换模型」切换正在用的那一个。总开关「使用 AI 整理」和「识别首页写下的计划」也在这里。设置首页这一行会显示「未开启」、正在用的供应商与模型，或「已开启 · 还没有填密钥」。
- **首页快速录入。** 写下一句计划后，会读出里面的日期、时段、时长、类型和重复，在这一行下面给一条建议，点了才改；一句话里有几件事时可以「拆成 N 条」。
- **拆成步骤。** 计划的更多菜单里多了「拆成步骤」；顺延印点开有「拆小一点／改期／放下」。拆出的步骤以草稿列出，可以改字、取消勾选，可选把原计划归档。
- **从文字或截图添加。** ＋菜单最后一项。粘贴一段通知、聊天记录或会议纪要，或者选一张截图，把里面要做的事找出来，列成计划草稿。截图里的字在本机识别，只把认出的文字发给模型，图片不上传。一次最多 6,000 字。
- **按这句话筛选。** 在计划库搜索框里写一整句话（如“上周没做完的学习计划”），可以一次设好类型、状态和日期范围，设完可以还原。
- **整理成清单。** 备忘正文的更多菜单里，把一段正文整理成核对清单。用了以后正文换成清单，保存前可以「还原正文」。
- **按内容预填每一行。** 备忘转计划时，按每一行的内容预填它自己的日期和类型，带浅色标注；不想用可以点「不用」。
- **起草复盘。** 周复盘编辑页顶部可以按这一周的计划记录起草复盘，并注明每一点依据的是哪几条计划；「放进两栏」后保存前仍能改，也能还原。
- **拟下周草稿。** 回顾的周总结里，按这一周的记录和“下周关注”拟下周计划草稿。
- **拟准备计划。** 新加一个还有两天以上的倒数日后，会出现一条提示，点了按剩下的天数拟准备计划。

**数据与隐私。** 只在你点了对应操作时，把当次要整理的文字直接发给你选的供应商，没有 Moji 的中转服务器。首页识别是例外：开着「识别首页写下的计划」时，带时间线索的新计划会在添加后自动发去识别，可以单独关掉。密钥只存在本机（iOS 钥匙串；Android 用系统 Keystore 加密后存在 App 私有目录），AI 设置和密钥都不进备份文件、App Group 和小组件。模型的回答只当数据读，日期在本机按你的时区计算。

## iOS 修复

- **启动时偶尔卡在第一帧。** 主线程保存数据时，如果“回到前台”的处理正好排在后面，会重新进入同一把存储锁，App 就停在第一帧不动。现在同一线程可以重入这把锁，只有最外层才去拿跨进程的文件锁，写入顺序改成先写文件再写设置。加了回归测试。

## Android

- 上面十项 AI 功能和「AI 模型」设置页全部做到 Android，各级菜单、按钮文字和顺序与 iOS 一致。
- 截图识字用 Google ML Kit 的中文识别模型，模型打在安装包里，在本机运行，不联网下载。因此 APK 从 1.7.0 的 14.7 MB 增至 59.7 MB：识字库按四种 CPU 架构各带一份，共约 39 MB（其中 x86 和 x86_64 两份约 22 MB，只在模拟器和少数 x86 设备上用到），模型约 1.8 MB。图片和认出的文字不会发给 Google，但按 ML Kit 的条款，它会把这项功能的使用和性能统计（如设备型号、调用次数、耗时、错误码）发给 Google。
- 安装包新声明了联网权限，用来直接连你选的 AI 供应商。Moji 自己的代码里只有 AI 请求会联网（另有上面说的 ML Kit 统计）。

## 不变的地方

- 保留 App ID `com.raydon.minuteplan`、Android 包名 `com.raydon.moji.android`、schema 13，数据格式没有变化，备份可以照旧在两端互相导入。
- Android 沿用原来的签名，可以直接覆盖安装 1.7.0。
