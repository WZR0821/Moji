# Moji 1.6.1（43）

作者：Jerry Wong。日期：2026-11-12。

本版只修正 Android 计划勾选的两处逻辑，让 Android 与 iOS 的既有行为一致。iOS 代码没有改动，只是与 Android 同步升级版本号。

## Android 勾选修正

- **已跳过的计划不再被勾成“已完成”。** 以前在“今日已结束”里点已跳过计划左侧的“−”，或在日历条目菜单中选“恢复为未完成”，计划会变成已完成。现在会恢复为未完成，并删除跳过时生成、但尚未开始的下一次重复计划。这与 iOS 的 `PlanStore.toggleCheckIn` 一致。
- **撤回完成只删除完成时那一条记录。** 以前撤回已完成的计划，会删掉这个计划名下的全部时间记录，包括之前中途结束的专注。现在只删除开始、结束时间与这次完成相符（误差 0.5 秒内）的那一条，其余记录保留。这与 iOS 的 `PlanCompletionReversion` 一致。
- 桌面小组件的勾选调用同一个函数，同样修正。

“记录已做”生成的完成，撤回时仍会删除它自己那一条记录，两端行为一致。专注进行中直接点勾选框的处理两端仍有差别，本版没有改动。

## 安装及兼容

- Android 使用原有发布签名，可以覆盖安装 1.6.0。iOS 提供未签名 IPA，需要重新签名后安装。
- 保留原 App ID、App Group、Widget ID 及 schema 13，数据格式没有变化。
- 覆盖安装前建议先备份。
