# Moji 1.5.0（40）验证与交付记录

日期：2026-10-06。开发基线是最新 1.4.1（39），不是旧的 1.4.0 安装包。本轮将原定 1.5／1.6 的功能合并交付，不增加账号、云同步或新的跨端架构。

## 功能与数据

双端实现备忘／清单转计划、计划复制、模板、计划库搜索筛选、批量整理及撤销、周目标、计划与实际对照、周复盘和待办结转。完整入口及规则见 [更新说明](RELEASE_NOTES_1.5.0.md)。

快照版本升至 schema 13，读取旧备份时为新增字段提供默认值；模板、目标、复盘和来源／归档信息参与备份与校验。保留 Bundle ID、App Group、Android application ID 和原 Android Release 签名。没有清空原数据或修改用户真机。

重点逻辑修复：

- 复制／模板不继承完成状态、实际记录、日历绑定和原重复序列；备忘转换按来源去重，保留全文。
- 批量操作跳过正在计时的计划；撤销核对操作后的值，保护其后的编辑、记录及暂停中的专注。
- 未计时的勾选完成不伪造分钟；跨周实际时段按重叠计算，短时段先汇总再转换为分钟。
- 编辑器保存成功后关闭，连续保存使用稳定草稿 ID；编辑保留来源、归档及重复发生关联。
- 专注开始先结算本机旧计时；提前结束不完成关联计划。自然结束、暂停累计、关联计划时长与阶段衔接按双端规则处理。

### 验证边界

对齐范围是应用自有页面的结构、信息、主要操作、配色、尺寸层级与资源；没有将截图结果表述为所有设备／字体设置下的逐像素一致性证明。系统状态栏、三键／手势导航、原生权限与文件／日期／时间选择器、转场及字体栅格化保留平台差异。

本轮未重新逐项执行历史全局状态矩阵：其他屏幕尺寸、大字体、横屏、真实软键盘组合输入、全部设置子页、系统日历／通知／Widget 权限流程与 iOS 实时活动仍需真机验收。专注运行和暂停的规则有测试，视觉截图中的专注为待机状态。没有对未执行的场景声称已通过。
