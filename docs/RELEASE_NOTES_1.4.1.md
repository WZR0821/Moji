# Moji 1.4.1（39）本地维护构建

本轮提供未签名 IPA，需要自行签名后安装。当前包由本地工作区构建，未上传商店；Android 源码版本已同步，未重新发布 Android 正式包。

- 修复损坏备份误识别为空快照、跨端小数秒日期和旧记录类型不兼容的问题。
- 恢复前校验条目并显示数量，保留恢复前本机副本；清除不可迁移的日历关联。
- Android 保留全天零时长记录，冷启动备份直接读取数据库；补齐分类、快捷预设和外观恢复。
- 备份与数据整理移到 Android 后台线程，合并频繁自动备份写入；iOS 减少重复快照解码，单文件预览后台读取。
- 修复快速勾选清单的旧状态覆盖；改善恢复弹窗、处理进度和错误提示。
- 增加双端备份回归测试与发布来源检查。

验证及已知边界见 [阶段总结与维护方案](DEVELOPMENT_REVIEW_2026-10-05.md)。本版本尚未完成真实设备后台计时和所有云盘提供方异常场景验收。
