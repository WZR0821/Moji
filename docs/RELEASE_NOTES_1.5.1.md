# Moji 1.5.1（41）

2026-10-07。作者名称统一为 **Jerry Wong**。保留 1.5.0 的计划库、模板、备忘转计划、批量整理、周目标及复盘功能，不引入账号、云同步或新的跨端架构。

## 双端界面与深层页面

- Android 按 iOS 调整应用内表单、导航栏、分段选择、开关、日期／时长胶囊和弹层顶部留白。设置子页及快速预设编辑页补齐返回层级、图标和相应操作。
- 计划展开详情的快捷编辑、标题／完整说明、底部操作按钮与滚动状态对齐。计划编辑器展开“更多选项”后的重复、提醒和系统日历分组对齐；新建时可以直接输入标题。
- Android 日历改为与 iOS 一致的月视图、每周分组列表和每日时段分组，补齐状态图例、年月跳转、所选日期添加及条目操作。完成计划与对应实际记录去重，未计时记录仍按日期展示。
- 校正 Android 红色印章中文字的实际字形居中；双端复用篆书字体、水墨位图及分隔线变体。
- 修正 iOS 备忘编辑页“完成”操作被工具栏挤掉的问题；计划库筛选、模板和记录编辑的间距调整。
- 双端周目标输入后仍保留字段标签；iOS 计划与记录编辑导航栏避免滚动文字透入顶部。
- Android 自动备份子页补齐保留期限（含永久）、立即备份、停止自动备份及文件夹恢复入口。停止只解除自动保存授权，不删除已有备份；恢复仍需先预览并确认。
- 双端“关于”页面显示 1.5.1 和 Jerry Wong；保留原有 Bundle ID、App Group、application ID、Android Release 签名和 schema 13 数据格式。

## 安装与验收

GitHub Release 提供签名 APK／AAB、未签名 IPA、工作区源码归档、视觉对照证据和 SHA-256 清单。iOS IPA 必须重新签名；保留数据时应沿用原签名身份及 App Group。

本次重点检查二、三级页面和已填写内容，具体执行场景及边界见 [验证记录](VERIFICATION_1.5.1.md)。应用自有布局以 iOS 为基准；系统状态栏、手势区域、原生权限／文件／日期选择器和字体栅格化仍有平台差异。截图验收不代表所有设备上的零像素差异。
