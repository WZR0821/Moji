# Moji 双端视觉一致性基线

更新日期：2026-08-13

## 一致性范围

Android 视觉层以 iOS 1.3.1 的 SwiftUI 页面和设计资源为唯一基线。两端保持一致的项目包括：

- 四个一级页面的标题、底部导航、信息层级与主要操作位置；
- 计划快捷输入、今日标题、计划行、空状态；
- 备忘搜索、分组、列表行和全屏编辑器；
- 倒数日、纪念日、专注三段结构与番茄钟圆环、阶段按钮、时长和操作区；
- 回顾摘要卡、指标、趋势、入口列表和设置索引；
- 纸张底色、墨色、次级墨色、朱砂色、圆角和字号层级；
- `InkFocusBloom`、`InkThinDivider`、`InkTimerRingDirectional`、`InkIconLoop` 等水墨位图直接复用 iOS 资源。

## 有意保留的平台差异

以下内容由操作系统控制，不参与像素一致性比较：

- 状态栏、底部手势/三键导航区域；
- 字体栅格化的细微差异；
- 系统权限弹窗、日期与时间选择器、文件选择器；
- Android 设置中的“系统日历”文案与备份文件夹，iOS 对应为 Apple 日历与 iCloud；
- iOS sheet 的系统圆角/遮罩与 Android 全屏 Dialog 的窗口转场。

## 视觉检查页

每次发布至少检查以下状态：计划空状态、备忘空状态、时刻空状态、专注待机、回顾空数据、设置索引。检查以相同屏幕宽度下的结构、颜色、字号层级、间距、卡片形态和按钮位置为准。
