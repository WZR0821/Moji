# Moji 双端视觉一致性基线

更新日期：2026-10-07

## 一致性范围

Android 视觉层以本轮 iOS 1.5.1（41）的 SwiftUI 页面和设计资源为基线。本轮实际检查 45 组浅色及 14 组深色双端状态，重点是展开详情、二级编辑器、三级设置和已有输入内容，证据及限制以 [1.5.1 验证记录](VERIFICATION_1.5.1.md) 为准。1.5.0 及更早矩阵保留作为历史范围，不计入本次实际截图数量。对齐项目包括：

- 四个一级页面的标题、底部导航、信息层级与主要操作位置；
- 计划快捷输入、今日标题、计划行、空状态；
- 计划展开的快捷编辑、完整信息、整行末项和滚动到底部后的操作；
- 计划“计划要做 / 记录已做”全屏编辑器、日期时间、时长、重复、提醒和日历开关；
- 月 / 周 / 日日历、日历事件列表和有数据标记；
- 备忘搜索、分组、列表行和全屏编辑器；
- 倒数日、纪念日、专注三段结构与番茄钟圆环、阶段按钮、时长和操作区；
- 倒数日全屏编辑器、番茄钟时长底部编辑器与输入后状态；
- 回顾摘要卡、指标、趋势、入口列表和设置索引；
- 周总结、月总结、时间记录分组列表及补记 / 编辑器；
- 周目标已有数字时的持久标签、已填写复盘和下周计划；
- 计划默认值、快速预设、番茄钟、提醒、外观、权限、备份和关于等设置子页；
- 纸张底色、墨色、次级墨色、朱砂色、圆角和字号层级；
- `InkFocusBloom`、`InkThinDivider`、`InkTimerRingDirectional`、`InkIconLoop` 等水墨位图直接复用 iOS 资源。

## 有意保留的平台差异

以下内容由操作系统控制，不参与像素一致性比较：

- 状态栏、底部手势/三键导航区域；
- 字体栅格化的细微差异；
- 系统权限弹窗、日期与时间选择器、文件选择器；
- Android 设置中的“系统日历”文案与备份文件夹，iOS 对应为 Apple 日历与 iCloud；
- 系统弹层遮罩／窗口转场；Android 应用内弹层已按 iOS 调整顶部留白和圆角。

## 全局状态矩阵

历史全局回归矩阵如下，作为后续检查清单保留；不表示 1.5.1 本轮重新逐项执行全部历史场景。本轮逐项实际执行列表见验证记录。

| 区域 | 状态 |
| --- | --- |
| 计划 | 空数据、有数据、已完成 / 未完成、长标题与备注、菜单 |
| 计划编辑 | 新建、编辑、记录已做、标题输入后、估算时长开启 |
| 日历 | 月 / 周 / 日、选中日期、计划 / 倒数日 / 实际记录混合列表 |
| 备忘 | 空数据、文本备忘、勾选清单、长文本、编辑器 |
| 时刻 | 倒数日 / 纪念日有数据、编辑器空值 / 输入后、更多设置 |
| 专注 | 待机、阶段切换、时长编辑、计划关联、开始 / 暂停 / 结束控件 |

| 设置 | 索引页、8 个子页、快速预设编辑与输入后、浅色 / 深色 |

检查以相同屏幕宽度下的结构、颜色、字号层级、间距、卡片形态、文本换行和按钮位置为准。历史 Android 截图位于 `build/qa-global/`；本次双端原图及并排图位于 `build/1.5.1-qa/`。原生字体字形度量和部分换行仍可能不同，截图检查不是逐像素、全设备一致性的证明。
