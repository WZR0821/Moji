# 本轮操作逻辑与 UI 对齐

范围：以当前 iOS 源码和上轮真实模拟器截图为参照，修正 Android 本地操作与界面。未修改 iOS 源码、备份编解码协议、迁移逻辑或发布版本号；未覆盖原有发布包。

## 已实现

- 重复计划：跳过、专注完成、将现有计划记为已做均生成后续事项；避免重复生成；空自选星期不再陷入循环。撤销时保留已经开始的后续事项。
- 记录：新增“已做”不再生成影子计划；删除最后一条关联记录恢复已完成计划；跨日编辑保留结束日期，阻止结束早于开始；统计按每日重叠时间分摊。
- 专注：暂停后阻止误换关联计划、阶段和时长；到期记录以原定结束时刻结算；手动结束不再触发自动下一阶段。时长上限与界面选择一致，修正计时刷新与深链入口。
- 提醒：变更后重新协调闹钟、取消旧提醒，触发时再验证事项和开关；通知声音开关生效，通知点击进入正确页面。
- 入口复用：MainActivity 使用 singleTask，避免通知/深链创建多个 ViewModel 与旧页面堆栈。
- 设置与小组件：自定义类型在本机持久化；纸墨纹理、运笔、常亮、触感连接实际行为；小组件从数据库读取新快照，过滤未来事项，三个快捷按钮使用配置值。系统返回键逐级退出设置。
- 备忘清单：以稳定 ID 逐项编辑、增删、勾选，避免删除前项后勾选状态串位。
- 编辑器：标题、说明、类型独立分组，增加自定义类型、完整安排方式和自选重复星期；日期/时间支持跨日，长字段不再强制固定行高；深色光标使用主题颜色。
- 二级页面：统一安全区、键盘避让、系统栏明暗；周/月总结增加历史浏览与分类图表；日历增加日/周时间轴、重复倒数日标记、记录编辑入口；更多和下一步入口具备动作。
- 系统日历保持单次添加语义，删除 App 内事项不自动删除系统日历副本。

## 尚不能宣称完成的部分

本轮是主要缺陷修复，不是全页面、全状态的像素级一致性验收。iOS sheet 与 Android 全屏页、原生键盘/日期选择器仍有平台差异；日历时间轴、图表的细节排版和非精确“已做”记录编辑还未完全复刻。小组件在不同桌面尺寸、真实设备触感/常亮、进程被终止后的自动阶段推进与后台提醒仍需单独验收。

备份安全校验、跨端日期/枚举兼容、非精确记录的跨端恢复、设置归档和源码发布归档的问题继续保留在原审查报告中，不能因本轮修复而标记通过。本轮没有进行广泛冗余清理，只删除了被新规则替换的旧重复计划计算函数。
