# Moji 1.6.0（42）

作者：Jerry Wong。日期：2026-10-12。

## 常用操作更直接

- 计划展开后直接点标题、备注、日期、安排、类型、重复或提醒，进入对应字段的小编辑器；不必先打开完整表单。
- 展开详情自动滚动到可见区域；日期、安排和类型使用整行宽度，长标题与说明可以自然换行。
- 计划库有独立的首页按钮；复制、模板、归档和删除集中到详情的“更多操作”。
- 专注入口区分“去专注”和“继续专注”，并说明是选择时长后开始，还是前往当前会话。
- Android 专注状态区分待开始、进行中、已暂停及完成，关联计划但尚未开始时不再误报暂停。
- 新建计划与补录已做事项使用明确的不同入口；编辑页不再放置容易误切的“记录方式”分段栏。高级设置默认收起，但仍显示已有设置摘要。
- 计划库默认先显示计划，筛选按需展开，并提供清除筛选；切换结果时不会继续选中已隐藏的项目，专注中的计划不能误加入批量操作。

## 编辑与返回保持一致

- 计划、记录、备忘、日子、周目标和周复盘的修改均使用“保存”；有未保存修改时取消需要确认。
- 备忘底部显示“转为正文／转为清单”“添加一项”等文字，减少只靠图标猜测操作；删除备忘和计划增加确认。
- 日子的更多设置返回到对应的新建／编辑页面，保留当前草稿。
- Android 快速添加、复制和周目标／复盘在保存成功后才清空输入或关闭页面。

## 逻辑及双端对齐

- 单字段编辑基于最新已保存的计划进行修改，不覆盖计时、完成状态、重复序列及其他未编辑字段。
- 改日期保留原时段和分钟；跨夏令时跳时的日期处理在两端采用相同规则。
- 旧计划修改其他字段时不会被自动加上预计时长；全天与投入估算继续相互独立。
- “跳过”不再计入今日完成数量；完成与跳过统一收在“今日已结束”。
- 统一重复规则文案与排序、编辑行高、输入区、日期／时间胶囊、底部操作区以及二级、三级页面的布局。实际截图范围和系统差异见验证记录。

## 安装及兼容

- Android 使用原有发布签名；iOS 提供未签名 IPA，需要重新签名后安装。
- 保留原 App ID、App Group、Widget ID 及 schema 13；不清空已有计划或备份。
- 覆盖安装前建议先备份。iOS 重签时应保持原有签名身份及兼容标识。
