# Moji

一款黑白朱红水墨风的原生 SwiftUI 计划打卡、备忘、番茄钟与纪念日 App。最低支持 iOS 17，已使用本机 Xcode 16.2 / iOS 18.2 SDK 验证。

## 四个主界面

### 计划

- 清单和日程是同一种计划数据，不设重复的日程模块。
- 首页只保留一句话快速添加和文字清单，默认不要求先填写时间。
- 标题输入兼容中文拼音候选组合态，点添加或保存时会先提交当前候选字。
- 点击清单内容后，二级展开只显示配置摘要、“详细设置”和“开始番茄钟”；日期、全天/上午/下午/晚上/精确时间、分钟级时长与类别统一收进第三级编辑页。
- 计划页左上角进入 Moji 自建日历，可在月、周、日三种视角间切换；同一日期会统一显示未来计划、进行中事项、已完成事项与独立的“记录已做”。
- 月视图以状态墨点快速浏览并在下方展开所选日期；周视图一次纵览七天；日视图按全天、上午、下午、晚上与具体时间分组。
- 支持每天、工作日、每周、自选星期和每月重复；重复规则在第三级详细设置中配置。
- 每个重复周期只能完成一次；完成或跳过后生成下一次，但到对应日期才重新出现在清单中。逾期完成会跳过已经错过的周期。
- 「今日计划」只收今天的事：安排在以后的计划留在日历里等自己那天，已完成的计划只属于完成当天，第二天不再跟随；折叠区「今日已归档」也只列当天完成或跳过的。
- 没做完的旧计划默认顺延到今天，可在设置 → 计划默认值 → 今日清单关掉；关掉后今日清单只显示安排在今天的计划，旧计划仍在日历和总结里。
- 顺延过来的计划在右侧盖一枚朱红方印，印文只有顺延天数（超过 99 天写 99+），计划标题与说明保持原样；计划小组件用同一枚印。
- 可为单次计划设置开始时、提前 5/15/30 分钟、1 小时或 1 天的本地提醒。
- 计划项左滑可直接顺延、跳过、修改或删除。
- 计划项可以直接带入番茄钟；结束后自动完成打卡并生成实际时间记录。
- 也可直接勾选完成；完成时先用一笔带飞白的真实毛笔笔迹划过标题，再收为水墨勾画，不会虚构实际计时时长。
- 详细设置中可为每一项单独选择是否写入 Apple 日历。

### 备忘

- 独立于计划、打卡和计时，只记录文字，不会进入完成率或番茄钟统计。
- 编辑页使用一张连续宣纸；留空标题时，正文首行会自然成为标题。
- 编辑页底部可切换「核对清单」；换行会继续添加项目，空心圆可直接勾选或取消，并可一键清除已完成项。
- 支持全文搜索、右滑置顶、右滑取消置顶、左滑删除与长按操作；置顶备忘使用方形「藏」篆书朱印。
- 备忘会随 Moji JSON 快照一起进入手动导出和「文件」App 自动备份。

### 倒计时

- 顶部用三段文字切换“倒数日 / 纪念日 / 专注”，只用一笔黑墨飞白标识当前模式；倒数日与纪念日各自成页，互不混排。
- 番茄钟沿用 v1.15 的真实毛笔圆环笔迹本身，只在动效上做文章：相位跑完后整圈墨迹停在纸上、晕开并加盖朱印，用户轻触才进入下一阶段；重置或跳过时才以水洗淡出收走。
- 专注、短休和长休时长都可在番茄钟页直接调整：菜单只给三四个常用值加「自定义」，任意分钟数在自定义页输入。关闭长休息后，番茄钟页不再显示长休一栏。
- 长休息在「设置 → 番茄钟」中开关；关闭后达到原长休息轮次时会继续进入短休息，自定义的长休息分钟数仍会保留。
- App 内运行番茄钟时显示锁屏实时活动和灵动岛，两处都可暂停、继续或结束；退出 App 则立即清理实时活动，计时和后台到时通知仍正常保留。
- 实时活动控制使用 `LiveActivityIntent` 在 App 进程执行；重置、跳过、自然结束和陈旧状态修复都会立即清理锁屏与灵动岛。
- 实时活动通过 `supplementalActivityFamilies([.small])` 提供 Apple Watch 智能叠放专用版式，手表上可直接暂停、继续或结束。该 API 需要 iOS 18，因此实时活动整体以 iOS 18 为门槛；iOS 17 上计时、通知和桌面小组件不受影响，只是没有实时活动与灵动岛。
- 番茄钟按绝对结束时间计算，App 进入后台后不会因为界面计时器暂停而丢失时间。
- 番茄钟状态由 App 级 `PomodoroEngine` 统一持有，切到其它页面后计时照常推进、到点照常落库。
- 重置、跳过或在锁屏结束本轮时，已专注满一分钟的时间仍会写成真实记录，关联计划退回待办而不是被标记完成。
- 纪念日按全天日历日计算：未来显示“还有 N 天”，过去显示“已经 N 天”。
- 未来日期进“倒数日”页，过去日期进“纪念日”页，卡片明确标注倒数或正数；左滑可修改或删除。
- 两页各自记住自己的排序方式：右上角菜单一键切到“按时间排序”，离今天最近的排在最前，重点标记的日期仍置顶；切回“手动排序”才能拖动调整顺序。
- 不足三天的未来倒数日以朱红标记。
- 支持不重复、每年、每月、每周以及“包含当天（+1）”，生日可按年重复。
- 添加倒数日或纪念日时，二级页只填写名称与全天日期；重复、计日预览、重点标记和日历同步统一放在第三级“更多设置”。
- 重复的纪念日（如生日）同时给出下一次的倒数天数与自当初起已经过去的时长，例如「已经 6 年 1 个月 · 共 2240 天」。
- 每个纪念日可选择写入 Apple 日历；写入时使用全天事件并携带相同的重复规则。
- 独立桌面小组件同步使用全天正数/倒数语义。

### 我的

- “我的”一级页只保留本周摘要与“总结 / 设置”两个入口。
- 总结二级页只显示周、月摘要与最近记录；完整图表和全部记录继续下钻。
- 日/周总结展示计划完成数、计划时间、实际时间以及学习/工作图表。
- 月总结提供带毛笔圆落印动效的完成率、完成热力图、连续打卡、计划与实际对比和学习/工作趋势。
- 设置二级页按“偏好 / 系统与数据”分为计划默认值、番茄钟、提醒与反馈、外观、权限、数据备份和关于；具体参数均在第三级页面调整。
- 设置中可以把计划、备忘、实际记录和纪念日导出为 JSON 备份，也可以导入恢复。
- 针对爱思助手普通 Apple ID 自签，专用 iCloud 容器备份已暂时关闭，避免因描述文件无容器权限而始终显示不可用。
- 「数据备份」可指定一个「文件」App 中的文件夹作为自动备份位置：数据每次变化都会写入最新快照，并每天另存一份历史备份，保留时长可选（默认半年）。重签安装后，首页会提示选择该备份并一键恢复。
- 备份设置会随备份一起继承：新装的 App 首次进入即弹出「先把旧数据接回来」，首选「选择备份文件夹恢复」——选中原来的备份文件夹后，Moji 会自动取出其中最新的一份恢复，并把这个文件夹重新设为自动备份位置，保留时长等设置也一并沿用。备份里还记着上次文件夹的名字，恢复提示会直接告诉用户该找哪个文件夹。
- 也可以只选单个备份文件恢复；这种方式 iOS 只授权了那一个文件，Moji 会尽量顺带取得所在文件夹的授权，取不到时会明确提示再去「回顾 → 数据备份」选一次文件夹。
- 总结、设置和隐私说明均收纳在个人界面。

## 桌面小组件与数据

- 桌面小组件保留三个，长按小组件「编辑小组件」即可挑选要显示的条目：
  - 「Moji · 倒数日」（2×4）显示最多三个还没到的日子，可分别指定三个位置；没选时自动按日期取最近的三个。同一个小组件也提供锁屏版式（矩形、圆形、单行文字），矩形版一次显示三个倒数日。
  - 「Moji · 纪念日」（2×4）同样可选三个，只显示已经过去的日子及其正数天数。
  - 「Moji · 计划」（4×4）显示三条计划，可直接点圆圈勾完，点整行跳进该计划的编辑页，底部保留三个快速添加预设。空位默认用今天的计划补齐，可在配置中关掉。
- iOS 没有 3×4 的小组件尺寸，计划小组件因此使用系统的 4×4（`systemLarge`）；旧的“打卡与计时”小组件按“只保留三个”的要求下线，其功能已并入计划小组件与实时活动。
- App、编辑页、总结、桌面小组件、锁屏与灵动岛共用黑白、轻宣纸纹理与少量飞白视觉语言；朱红收敛为临近日期、删除和小型朱印等语义状态。

## 工程与构建

直接打开 `Moji.xcodeproj` 即可运行。构建未签名 IPA：

```bash
DEVELOPER_DIR=/path/to/Xcode.app/Contents/Developer \
  ./Scripts/build_unsigned_ipa.sh
```

每次交付会递增版本号与构建号，并保留版本化文件，例如
`dist/Moji-v1.0.1-build32-unsigned.ipa`；`dist/Moji-unsigned.ipa`
始终作为最新版快捷文件。

未签名 IPA 不能直接安装到普通 iPhone，需要使用个人或开发者证书重新签名。若要让 App 与小组件共享数据并延续旧数据，重签名时需要为两个 target 配置同一个可用的 App Group，并保持下方列出的 bundle identifier。

## 重签更新时保留数据

覆盖安装能否被 iOS 识别为“同一个 App”，由签名后的应用身份决定，而不是 IPA 文件名。以后每次重签请固定以下旧版兼容标识，以保证覆盖安装、既有数据和桌面小组件继续有效：

1. 主 App Bundle ID：`com.raydon.minuteplan`
2. 小组件 Bundle ID：`com.raydon.minuteplan.widget`
3. App Group：`group.com.raydon.minuteplan`

爱思助手普通 Apple ID 自签时，请在「设置 → 数据备份」选择 iCloud 云盘文件夹。换签后的新沙盒无法继承文件夹授权，首次启动时需从同一云盘文件夹手动选取最新备份一次；恢复后再重新选定该文件夹，后续数据会继续自动备份。
